概览

这个实验想看看：一小批《雾山五行》的动画截图，能教会 Stable Diffusion 多少东西——那种水墨感的天空、密林、瀑布，以及大量的中式传统建筑，构成了这部动画的画面语言。

训练出来的 LoRA 在这套词汇内表现不错，一旦超出就明显退化：prompt 离风景越远，风格越挂不住，细节也偏软。对一个小数据集的风格实验来说，这个边界本身才是最有意思的部分。

用到的技术

LoRA（低秩适配）
在冻结的 Stable Diffusion 的注意力层上挂一组很小的可训练矩阵，只训练这部分。正因为只训这一点点，几十张图、一张显卡就够了。
触发词
训练时把这套风格绑定到 rog_mountain 这个词上，因此只有 prompt 里出现它的时候，风格才会被激活。
高清修复（Hires fix）
先在 512px 下出图，再放大并以 0.7 的重绘幅度重新去噪，让补出来的细节沿着同一种风格走，而不是跑偏成另一种画风。

Prompt

rog_mountain, scenery, water, cloud sky, forest, traditional Asian architecture
