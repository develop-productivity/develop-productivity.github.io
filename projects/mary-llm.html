Overview

Mary LLM is a study project: instead of fine-tuning an existing checkpoint, every stage of the language model pipeline is written out and run — training a tokenizer on the corpus, defining the model architecture, pre-training it on next-token prediction, then aligning it with supervised fine-tuning and preference optimization.

The point is not a competitive model. It is to keep each stage small enough to read and cheap enough to re-run, so the effect of a stage is visible. The final checkpoint is served through a Gradio interface for quick manual testing.

Techniques used

The four stages, and what each one actually does.

Tokenizer
Text has to become integers before a model can read it. A tokenizer is trained on the corpus itself so that common Chinese sequences get a single token, which keeps the vocabulary compact and the sequences short.
Pre-training
Next-token prediction on raw text. The model only learns to continue text here — it does not yet know how to answer a question.
SFT (supervised fine-tuning)
Training on instruction–response pairs, which is what turns a text continuer into something that replies to a prompt.
DPO (direct preference optimization)
Alignment from pairs of preferred / rejected answers. It optimizes the same objective RLHF targets, but directly on the pairs, so no separate reward model or RL loop is needed.
